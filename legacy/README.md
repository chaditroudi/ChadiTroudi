# Legacy: bootcamp and learning platform

This folder holds the earlier version of the site: the Java bootcamp, tutoring and pricing pages, the gamified learning platform (`src/pages/platform`), AI tutor and voice components, the Supabase functions and the Spring Boot blog back-end (`backend/`).

It was removed from the live portfolio so the site serves a single audience: people hiring a developer. Nothing here is built, linted, type-checked or deployed.

- To bring it back as its own product, move it to a separate repository. Its dependencies are listed in the root `package.json` from before commit "Focus the site on hiring" (see git history).
- The old portfolio components are in `src/components/portfolio`.
